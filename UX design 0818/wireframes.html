01 — Global rules · apply to every screen

Typography constraints

RuleValue
line-heightNever below 1.0. Body 1.5, UI labels 1.3, display type 1.15–1.2.
display typeBottom padding ≥ 0.16em, and headroom above the cap line equal to the tallest stacked diacritic. Verify on Tuyển chọn có "gu", Nhà cửa, Đồ gỗ.
maskingText masks and clip reveals operate at word or line level. No per-glyph overflow:hidden.
transformsAny transform on display-size type keeps the diacritic inside the mask at every frame of the animation, not only at rest.
hero imagesNo text baked into image assets — untranslatable for the EN build, and lost under crop.

Touch, focus, motion

RuleValue
tap target≥44×44px of hit area, achieved with padding or an expanded hit region. Visual size is independent — a 22px glyph with 11px padding satisfies this.
spacing≥8px between adjacent targets.
focusVisible ring on every interactive element. Full keyboard path through all controls.
alt textEvery image. Map pins mirrored by a text list.
reduced motionUnder prefers-reduced-motion every motion below resolves to its end state instantly. Function is preserved; travel is removed.
autoplayAny loop with a cycle under 5s carries a visible pause control.

Implementation baseline

ItemValue
techniqueNative CSS animation-timeline: scroll() / view(), plus scroll-snap and the View Transitions API. No JavaScript animation library.
threadScroll-driven animations run on the compositor. No scroll event listeners driving style.
fallbackanimation-fill-mode: both throughout, so unsupported browsers render the end state. Layout never depends on an animation completing.
scroll ownershipNative scroll only. No scroll interpolation or smooth-scroll library — MO-3, MO-4, MO-5 and MO-7 all depend on the browser's own scroll position.
LCPNo entrance animation above the fold. Hero frame 1 loads eagerly, all later frames lazily. Target LCP < 2.5s. HP-01

Structural constraints on screens already drawn

WhereConstraint
headerThe logo is a single lockup at 82:50 — "Tí" stacked over "COOLTURE", the T crossbar spanning the full width. It cannot be split. At the shrunk 44px bar (MO-3) it renders ~28px tall × 46px wide with 8px of clearance; at the 72px bar, ~40 × 66px. MO-3's wordmark scrub animates the lockup's width, not a font-size.
footer
MO-4		The revealed wordmark is the lockup as SVG, not live text. This removes the diacritic-clipping risk from that element entirely — the í is vector. The line-height and padding rules in §01 still govern every Vietnamese heading elsewhere.
footer edgebrand-wave-bottom is 1920×698 — 698px is roughly a whole mobile viewport. Full height is only viable as the top edge of the revealed footer panel, where it becomes the seam between content sheet and footer. Use brand-wave-bottom-extended (1915×349) anywhere the wave sits inside normal page flow.
herobrand-arc-top-right reads as a frame or mask for the hero's top-right corner. Any masking of hero images must stay outside the 15% top and bottom safe zone in the submission spec, or shop-supplied images get clipped twice.
logo detailThe double-O carries an interior mark. Below roughly 80px lockup width it fills in. Establish a minimum size and a simplified variant for anything smaller.
teal on whiteAt 1.8:1 the teal is invisible as a hairline on white. Dividers, borders and the collapsed Hidden Gems tab edge need a darker stroke or a filled treatment.

02 — Motion reference · live · scroll and swipe inside each frame

MO-1 Scroll progress
CÂU CHUYỆN THƯƠNG HIỆU
↕ 3px bar, pinned top, scrubbed by scroll position
SPEC
Height 3px, full-bleed, sits above the header. Scale transform from origin left. Present on long-form pages only — blog post, brand story, About. Not on grids.
.progress{
  animation:grow linear both;
  animation-timeline:scroll();
  transform-origin:0 50%;
}
MO-2 Parallax & settle
DRIFT — ảnh lớn
SETTLE — thẻ sản phẩm
↕ two variants — drift for large images, settle for cards
DRIFT
Image sits at 128–135% of its frame and translates ±9% across the frame's full view range. For hero, shop cover, blog header, and the product gallery's main image.
SETTLE
Scale 1.08 → 1.00 across the entry range, inside an overflow:hidden wrapper. For every product card image in every grid, carousel and related-products row.
LIMIT
Travel never exceeds 10%. Drift and settle are never combined on one element.
.settle{
  animation:settle linear both;
  animation-timeline:view();
  animation-range:entry;
}

SPEC
scroll-snap-type:x mandatory, scroll-snap-align:start, scroll-snap-stop:always so one flick advances exactly one item.

Item width 84% for full-width media, 62% for product cards. The visible edge of the next item is the swipe affordance.

SPEC
Cross-document view transitions. @view-transition{navigation:auto} in the global stylesheet; the shared element carries a view-transition-name on both the origin card and the destination page.
NAME
Unique per visible element — generated from the record slug, never a shared static name.
PAIRS
Applied site-wide, not only to products: product card → product page (image) · shop card → shop page (logo + cover) · blog card → post (header image) · collection tile → collection page (tile image) · map stop card → shop page (thumbnail) · hero credit pill → shop page.
DIR
Sibling navigation — blog topic to topic, district to district, stop to stop — uses a directional slide: forward left, back right.
ROOT
Pages without a shared element cross-fade the root. No navigation is a hard cut.
/* global stylesheet, both pages */
@view-transition{ navigation:auto; }

/* origin card and destination page */
.product-image{ view-transition-name:product-{slug}; }
.shop-logo    { view-transition-name:shop-{slug}; }
