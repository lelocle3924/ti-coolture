## PHẦN C — QUY CÁCH ẢNH

Khi chưa có ảnh thật, **đừng dùng ảnh stock**. Dùng khối màu `--paper-warm` có nhãn ở giữa:

```
┌─────────────┐
│             │
│  ẢNH 1:1    │   ← chữ .label, màu --color-text-muted
│  1200×1200  │
│             │
└─────────────┘
```

| Loại | Tỷ lệ | Kích thước tối thiểu |
|---|---|---|
| Ảnh sản phẩm | 1:1 | 1200×1200 |
| Ảnh cover shop | 21:9 | 2100×900 |
| Logo shop | 1:1 | 500×500, nền trong suốt |
| Ảnh bìa bài viết | 3:2 | 1600×1067 |
| Ảnh điểm dừng lộ trình | 4:3 | 1200×900 |

> ⚠️ **Cảnh báo ở đầu Phần B vẫn còn nguyên giá trị.** Tên shop, tên sản phẩm,
> giá, lộ trình, tiêu đề bài viết — tất cả là **giả định**. Chúng nằm trong code
> để dựng giao diện, **không phải để lên bản demo công khai**. Thay bằng shop
> thật trước khi công bố.

Ảnh: không dùng ảnh stock (brief §8 cấm). Chỗ nào chưa có ảnh thật thì sinh
khối placeholder bằng SVG data-URI đúng tỷ lệ và nhãn ở Phần C — hàm
`placeholderImage()` trong cùng file.

Copy giao diện ở Phần A đã dùng trong bản dựng: ghi chú giá, tuyên bố miễn trừ,
trạng thái rỗng, thông báo lỗi. Nhãn section dùng bản tiếng Việt
("Đang có trong kho", "Lộ trình khám phá", "Viên ngọc ẩn").

Bổ sung ngoài content pack gốc:
